# Pilas

**Tú enseñas. Pilas avisa.** Prototipo de una app para registrar cobros y recordar mensualidades en academias deportivas.

- Página de prueba: https://gabrielelc02.github.io/pilas/
- Tres marcas con la misma app: `bateria/` (La i que carga), `ojo/` (Ojo pelao) y `monedas/` (La pila de monedas).
- Ojo pelao en tres paletas nuevas (regla 60-30-10 y colores de estado fijos): `senal/` (marino y amarillo, la recomendada), `usopen/` (azul pista y naranja arcilla) y `fintech/` (azul petróleo y verde esmeralda). Guardan sus datos aparte. Página para abrirlas: https://gabrielelc02.github.io/pilas/paletas/
- Cada marca se instala en el teléfono como app (PWA) y funciona sin internet.
- Usa datos de ejemplo y guarda todo solo en el teléfono de quien la prueba.
